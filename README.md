# admin-painel-jus9-tecnologia-juridica

Repertorio destinado ao painel administrativo e ao futuro Dashboard do Clovis, como tela interna de comando do fundador.

## Memoria operacional

- Lembrar de investimento + Dashboard do Clovis como prioridade de MVP.
- Dashboard do Clovis deve reunir APP/MVP, servidores locais, agenda, WhatsApp privado, repertorios criticos, governanca e captacao.
- Nao publicar dados reais, financeiros, juridicos ou pessoais sem camada de seguranca adequada.
